# How to Manage Java Version in AT Launcher

To change the Java version for a specific instance in AT Launcher:

1. Open **AT Launcher**, navigate to the **Instances** tab, and click the **Settings** button for your instance.
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/8db5f666-17dd-4345-986b-2d201269929f" />

2. In the instance settings window, switch to the **Java/Minecraft** tab.
3. Locate the **Use Java Provided By Minecraft?** dropdown menu and change its value to **No**.
<img width="786" height="593" alt="image" src="https://github.com/user-attachments/assets/a7797bbe-8cd3-4f18-9d56-a359896226b3" />

4. A warning popup will appear. Click **Yes** to confirm you want to use a custom Java version.
<img width="542" height="128" alt="image" src="https://github.com/user-attachments/assets/559cd06b-cbc1-4c1c-a67c-2f5cd26b2bfe" />

5. Click the **Browse** button next to the **Java Path** field to select the specific Java installation you wish to use.
<img width="786" height="593" alt="image" src="https://github.com/user-attachments/assets/565b3d4a-c0b5-48e0-ad67-5aaa25f68231" />

6. Click **Save** at the bottom to apply the changes.
