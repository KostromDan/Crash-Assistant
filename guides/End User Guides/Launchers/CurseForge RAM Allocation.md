# How to Manage Memory Settings for a Specific Profile in CurseForge

To change the amount of RAM allocated to a specific Minecraft profile:

1. Open the **CurseForge** app and go to the profile there you want to change ram allocation.
2. Click on the **three vertical dots** (menu icon) next to the "Play" button and select **Profile Options**.

<img alt="image" src="https://github.com/user-attachments/assets/b2f494e7-090c-4a04-a8b6-3a40e03349b6" />

3. In the **Memory Settings** section, toggle the **Custom RAM Allocation** option.
4. Adjust the slider to your preferred amount of RAM (e.g., 4096MB).

<img alt="image" src="https://github.com/user-attachments/assets/40bf238b-f5c1-4aa1-825d-1f091c577d65" />

5. Click **Done** to apply the changes.
