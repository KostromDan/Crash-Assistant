# How to Manage Memory Settings in CurseForge Launcher

To change the amount of RAM allocated to Minecraft in the CurseForge app:

1. Open the **CurseForge** app.
2. Click on the **Settings** (gear icon) located in the bottom-left corner of the window.
3. Select **Minecraft** from the list of games in the left sidebar.
4. Scroll down to the **Java Settings** section.
5. Use the **Allocated Memory** slider to set the desired amount of RAM.
    - *Note: It is generally recommended to set this between 4096MB and 8192MB for modded play.*
