# How to Manage Java Version in Prism Launcher

To change the Java version for a specific instance in Prism Launcher:

1. Open **Prism Launcher** and select the instance you want to modify.
2. Click the **Edit** button in the right-side menu.

<img alt="image" src="https://github.com/user-attachments/assets/a9da94c7-8bfa-4ab2-a3e4-a5550da8f0ff" />

3. In the instance settings window, select the **Settings** tab from the left sidebar.
4. Check the **Java installation** box to enable manual selection.
5. Click the **Browse** button to navigate to and select the specific Java version you wish to use.

<img alt="image" src="https://github.com/user-attachments/assets/aa7479d4-19f5-4534-aa3a-0d986365167b" />

6. Click **Close** at the bottom right to save your settings.
