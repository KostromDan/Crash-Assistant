# How to Manage Memory Settings in Prism Launcher

To change the amount of RAM allocated to a specific instance in Prism Launcher:

1. Open **Prism Launcher** and select the instance you want to modify.
2. Click the **Edit** button in the right-side menu.
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/bf4c3d8a-30af-40f9-9037-7af10648942b" />

3. In the new window, select the **Settings** tab from the left sidebar.
4. Check the **Memory** box to enable custom allocation.
5. Adjust the **Maximum memory allocation** to your desired value (e.g., 4096 MiB).
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/8b746b92-0875-44f4-b43d-cd32e1999a27" />

6. Click **Close** at the bottom right to save your settings.
