# How to Manage JVM Arguments in CurseForge Launcher

To add or change JVM arguments in the CurseForge app:

1. Open the **CurseForge** app.
2. Click on the **Settings** (gear icon) in the bottom-left corner.
3. Select **Minecraft** from the side menu.
4. Scroll down to the **Java Settings** section.
5. In the **Additional Arguments** text box, you can add or modify your JVM flags.
