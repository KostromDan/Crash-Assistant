# How to Manage JVM Arguments in Prism Launcher

Prism Launcher allows you to set JVM arguments globally or per instance.

### Option 1: Global Settings
1. Open **Prism Launcher**.
2. Click **Settings** in the top toolbar.
3. Select the **Java** tab on the left.
4. Add your flags into the **JVM arguments** text field.

### Option 2: Instance-Specific Settings
1. Right-click on your Minecraft instance and select **Edit**.
2. Go to the **Settings** tab.
3. Check **Java** to enable overrides.
4. Modify the **JVM arguments** box.
