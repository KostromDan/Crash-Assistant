# How to Manage JVM Arguments in AT Launcher

To add or modify Java parameters for a specific instance in AT Launcher:

1. Open AT Launcher and click the **Settings** button for your chosen instance in the **Instances** tab.
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/8db5f666-17dd-4345-986b-2d201269929f" />

2. Switch to the **Java/Minecraft** tab in the instance settings.
3. Find the **Java Parameters** text area and enter your custom JVM flags.
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/e061ad03-c441-4f60-a681-2c45fe6525f0" />

4. Click **Save** to confirm the new parameters.
