# How to Manage JVM Arguments in Prism Launcher

To add or change JVM arguments for a specific instance in Prism Launcher:

1. Open **Prism Launcher** and select the instance you want to modify.
2. Click the **Edit** button in the right-side menu.
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/bf4c3d8a-30af-40f9-9037-7af10648942b" />

3. In the instance settings window, select the **Settings** tab from the left sidebar.
4. Check the **Java arguments** box to enable the text field.
5. Enter your desired JVM flags in the text box below.
<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/e7a259ec-2c55-460d-94be-1a562a99bfec" />

6. Click **Close** to save your changes.
