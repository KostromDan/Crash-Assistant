# How to Manage Java Version in CurseForge Launcher

> [!WARNING]
> Unfortunately, CurseForge currently only allows you to change the Java **vendor** or minor version, not the major version itself. This means if a game is designed for Java 17, you cannot run it using Java 21. If you need to switch the actual major Java version, we recommend using **Prism Launcher** or **AT Launcher**.

To manage the Java executable used by CurseForge:

1. Open the **CurseForge** app and click on the **Settings** (gear icon) in the bottom-left corner.

<img width="1259" height="1023" alt="image" src="https://github.com/user-attachments/assets/18939389-c35f-49a4-97c5-e4ae62e75caf" />

2. Select **Minecraft** from the "Game Specific" list in the side menu.
3. **Scroll down** to the **Java Versions** section, as it is located at the bottom of the page.
4. Click the **Choose** button next to the desired Java version to select a specific vendor's installation.
