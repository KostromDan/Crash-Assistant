# How to Manage Memory Settings in Prism Launcher

Prism Launcher allows you to set memory limits globally or for specific instances.

### Option 1: Global Settings (For all instances)
1. Open **Prism Launcher**.
2. Click the **Settings** button in the top toolbar.
3. Select the **Java** tab on the left.
4. Under **Memory**, adjust the **Maximum memory allocation** (and minimum if needed).

### Option 2: Instance-Specific Settings
1. Right-click on the specific Minecraft instance you want to configure.
2. Select **Edit** from the context menu.
3. Go to the **Settings** tab in the sidebar.
4. Check the box for **Java** to enable instance-specific overrides.
5. Adjust the **Maximum memory allocation** value.
